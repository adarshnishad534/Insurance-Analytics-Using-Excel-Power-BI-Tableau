# Insurance Analytics Project

## Project Overview
This project focuses on analyzing insurance data using **Microsoft Excel, Power BI, and Tableau** to generate meaningful business insights and support data-driven decision-making.

The project includes data cleaning, data analysis, KPI development, and interactive dashboard creation to understand insurance policy performance, premium revenue, claims, and customer trends.

## Tools & Technologies
- **Microsoft Excel:** Data Cleaning, Data Analysis, Pivot Tables, KPI Dashboard.
- **Power BI:** Power Query, DAX, Data Modeling, Interactive Dashboard.
- **Tableau:** Data Visualization, Calculated Fields, Interactive Dashboard.

## Project Objectives
- Analyze overall insurance policy performance.
- Understand total premium revenue and claim amounts.
- Identify customer and policy trends.
- Analyze claims across different categories.
- Develop interactive dashboards for business insights.
- Support data-driven business decisions.

## Key Performance Indicators (KPIs)
- Total Policies
- Total Customers
- Total Premium Amount
- Total Claim Amount
- Average Premium Amount
- Average Claim Amount
- Policy Status Analysis
- Claims Performance Analysis

## Project Workflow
1. Data Collection
2. Data Cleaning and Preparation
3. Exploratory Data Analysis (EDA)
4. KPI Identification
5. Dashboard Development in Excel
6. Interactive Dashboard Development in Power BI
7. Data Visualization in Tableau
8. Business Insights and Recommendations

## Business Insights
The project aims to identify:
- Insurance policy distribution and performance.
- Premium revenue trends.
- Claim amount patterns.
- Customer behavior and policy preferences.
- Opportunities to improve insurance business performance.
